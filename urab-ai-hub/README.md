# `urab-ai-hub/` — Página de entrada

La página de bienvenida del sistema. Es lo primero que ve alguien que llega: una pantalla simple que **enlaza a los tres portales** (ciudadano, funcionario y coordinación).

**En producción:** `urab-ai-hub.vercel.app`

## Qué contiene

| Archivo | Qué es |
|---------|--------|
| `index.html` | La página completa: una sola página estática, sin servidor propio. Elige a qué portal entrar. |

No usa framework ni necesita instalación: es HTML con estilos incluidos. Se despliega en Vercel como sitio estático.
